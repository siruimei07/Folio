- 结果写在 [`../icloud-field-test.md`](../icloud-field-test.md)。实际执行的是 `logs/run3/`（文件夹 `FolioTest2`）；`run1/` 是只有 Windows 的试跑，`run2/`（文件夹 `FolioTest`）被 NFD 双胞胎卡住后由 Sirui 在 iPad 上删掉。
- 第二版去掉了快捷指令：iPad 上只用「文件」App 的点按、长按、重命名、删除、复制，以及「标记」（在图片上画一笔）。

## 怎么配合

- **我一步一步带你做。** 我在聊天里说“做第 N 步”，你照下面第 N 步做，做完按“回复我”那一栏回一句话。
- **时间由我记。** 你不用记时间，回复的那一刻就算时间点。
- **截图不是必需的。** 只有第 5 步建议截一张。
- **看不到某个文件也是结果。** 照实回复就行，比如“没有这个文件”“iPad 不让改这个名字”。
- 所有测试都在 **iCloud 云盘 → `FolioTest2`** 文件夹里。旧的 `FolioFieldTest` 文件夹不用管，测完我来处理。

## 常用操作（iPad「文件」App）

| 操作 | 怎么做 |
|---|---|
| 打开测试文件夹 | 「文件」→ 左栏「浏览」→ **iCloud 云盘** → **FolioTest2** |
| 刷新 | 在文件列表里**往下拉**再松手 |
| 打开文件 | 点一下。`.txt` 会显示文字，`.png` 是一个纯色方块 |
| 重命名 | **长按**文件 → **重新命名** → 改名 → 键盘上的**完成** |
| 复制一份 | **长按**文件 → **复制**：会出现一个名字带“ 2”的副本 |
| 删除 | **长按**文件或文件夹 → **删除** |
| 在图片上画一笔（标记） | 点开 `.png` → 右上角的**笔尖图标**（标记）→ 随手画一道 → 左上角**完成** |
| 存照片或视频到文件夹 | 「照片」→ 选中 → **分享** → **存储到“文件”** → 选文件夹 → **存储** |
| 飞行模式 | 从右上角往下拉出控制中心 → 点**飞机**图标，并确认 **Wi-Fi 图标是灰的**（没连 Wi-Fi） |

颜色约定：我放的图片一开始都是**红色**方块；我在 Windows 上改过的会变成**绿色**、**蓝色**或**黄色**。你画过一笔的，就是“原来的颜色 + 你的线”。

## 附：每一步要回答的问题（testing-strategy）

| 步 | ADR-0003 行动项 4 的问题 | 不弄清的风险 | 怎样算回答清楚 |
|---|---|---|---|
| 1 | iCloud 不同步的名字 | Folio 自己的文件或空文件不被同步 | 每个名字在 iPad 上出没出现 |
| 2 | NFD 名字、Windows 上不合法的名字 | 导入出现 NFC/NFD 双胞胎；坏名字让同步卡住 | 每个名字在两边的样子（码位）、有没有到达、有没有被改名 |
| 3 | 只改大小写的重命名 | 重命名被当成删除加新建；大小写双胞胎互相覆盖 | 两个方向的结果；双胞胎的去向 |
| 4 | 更新怎样到达已下载 / 未下载的文件，watcher 看不看得到 | Folio 漏掉远端修改，或把下载误当修改 | watcher 记录（原始的和 Folio 的）、file id、占位符状态、内容 |
| 5 | 远端删除会不会进回收站；Windows 删除后 iPad 的“最近删除” | 远端删除让文件永久消失 | 回收站、iCloud `.Trash`、iPad 最近删除里各有什么 |
| 6 | 固定的文件夹里新文件会不会继承固定 | `.folio/store/` 新到的 pack 仍是占位符，读取时卡住 | 新文件的固定属性、是否自动下载、用时 |
| 7 | 改名覆盖还是先删再移入 | 留下临时文件、原文件丢失；iPad 收不到新内容 | 三种写法 × 3 轮：iPad 看到的内容、多出的文件、Windows 上的残留 |
| 8 | head 记录和大 pack 的先后、延迟 | 读的一方先看到 head，pack 还没到 | 两个方向的到达时间和顺序 |
| 9 | 两边同时修改时冲突副本的命名 | 认不出冲突副本；假云端用错命名 | 冲突副本的确切名字、哪边赢、出现在哪边 |
| 10 | 两边同时新建 | 同上 | 同上 |
